# 『ポンっ！』

**テキストを入力するだけで、スライドがポンっと完成。**

「ポンっ！」は、入力したテキストからスライドを自動作成し、PowerPoint形式（`.pptx`）で保存できるWebアプリです。

Markdownを直接入力するだけでなく、画面上の「要素を追加」ボタンから見出し・リスト・表などを挿入できるため、Markdownの書き方を知らなくても利用できます。

## できること

- 入力したテキストをリアルタイムでスライド化
- Markdownを知らなくても「要素を追加」から入力可能
- スライドをブラウザ上でプレビュー
- PowerPoint形式（`.pptx`）で出力
- Markdownファイルの読み込み・保存
- 全画面プレゼンテーション
- スライドごとのグリッドレイアウト
- 表の作成
- 箇条書き・番号付き・ネスト付きリスト
- 引用・二重引用
- コードブロック
- 数式
- 太字・斜体・リンク・強調色
- 色・文字サイズ・余白などのデザイン設定
- 設定内容のブラウザ保存

# 基本的な使い方

## 1. スライドの内容を入力する

画面のMarkdown入力欄へ、スライドにしたい内容を入力します。

```markdown
# ポンっ！について

ポンっ！は、テキストからスライドを作成できるアプリです。

## 特徴

- テキストを入力するだけ
- スライドを自動作成
- PPTX形式で保存可能
```

入力した内容は、自動的にスライドプレビューへ反映されます。

## 2. プレビューを確認する

Markdownを変更すると、スライドのプレビューもリアルタイムで更新されます。

文章量、文字の折り返し、グリッドの並び方などを確認しながら編集できます。

## 3. デザインを変更する

ヘッダーの「スライド設定」から、スライドのデザインを変更できます。

### カラー

- メインカラー
- 背景色
- 本文色
- アクセントカラー
- コードブロックの背景色
- 表のヘッダー背景色

表のヘッダー文字色は、背景色に合わせて白または黒が自動的に選択されます。

### 文字サイズ

- スライドタイトル
- 小見出し
- 本文
- コード
- 数式
- ページ番号
- タイトルスライドのタイトル
- タイトルスライドのサブタイトル

### レイアウト

- スライド内の余白
- コンテンツ間の余白
- ページ番号の表示
- タイトルスライドの表示

変更した設定はブラウザの`localStorage`へ保存され、次回アプリを開いたときにも引き継がれます。

## 4. 全画面で確認する

プレゼンテーションボタンを押すと、スライドを全画面で確認できます。

| 操作               | 動作             |
| ------------------ | ---------------- |
| `←`                | 前のスライド     |
| `→`                | 次のスライド     |
| `Space`            | 次のスライド     |
| `Escape`           | 全画面表示を終了 |
| 画面左側をクリック | 前のスライド     |
| 画面右側をクリック | 次のスライド     |

## 5. PowerPointとして保存する

ヘッダーの「PPTXを出力」を押すと、作成したスライドをPowerPoint形式で保存できます。

出力するファイル名は、Markdown入力欄の上部から変更できます。

# Markdownを知らない場合

Markdownの書き方を覚えていなくても、「要素を追加」ボタンから必要な要素を挿入できます。

## 要素を追加する

1. Markdown入力欄の挿入したい位置をクリックします。
2. 入力欄右下の「要素を追加」ボタンを押します。
3. 画面下から表示されるシートでカテゴリーを選びます。
4. 挿入したい要素を選びます。
5. カーソル位置へ対応するMarkdownが挿入されます。
6. 選択されている仮の文字を、そのまま書き換えます。

カテゴリーは横方向へスクロールできます。

## 選べる要素

### スライド

- 新しいスライド
- グリッドレイアウト
- 次の列

### 文章

- 小見出し
- コンテンツ見出し
- 本文
- 引用
- 表

### リスト

- 箇条書き
- 番号付きリスト

### 文字装飾

- 太字
- 斜体
- 強調色
- リンク

### その他

- コードブロック
- インライン数式
- ブロック数式

## 選択した文字を装飾する

Markdown入力欄で文字を選択してから、要素挿入シートの「太字」や「強調色」を押すと、選択した文字をそのまま装飾できます。

例として、次の文字を選択します。

```text
重要な部分
```

「太字」を選ぶと、次のようになります。

```markdown
**重要な部分**
```

「強調色」を選ぶと、次のようになります。

```markdown
==重要な部分==
```

# スライドの作り方

## 新しいスライドを追加する

見出し1を記述すると、新しいスライドが作成されます。

```markdown
# スライドタイトル
```

複数のスライドを作る場合は、スライドごとに見出し1を記述します。

```markdown
# 1枚目のスライド

1枚目の内容です。

# 2枚目のスライド

2枚目の内容です。

# 3枚目のスライド

3枚目の内容です。
```

見出し1は、スライドタイトルとページの区切りを兼ねています。

## 小見出し

見出し2は、スライド内の小見出しとして表示されます。

```markdown
## 小見出し
```

小見出しの文字色には、スライド設定のアクセントカラーが使用されます。

## コンテンツ見出し

見出し3〜6は、本文内の見出しとして表示されます。

```markdown
### コンテンツ見出し

#### 見出し4

##### 見出し5

###### 見出し6
```

# 文章の書き方

## 本文

通常の文章は、そのまま入力します。

```markdown
これはスライドの本文です。
```

段落を分けたい場合は、文章の間に空行を入れます。

```markdown
これは1つ目の段落です。

これは2つ目の段落です。
```

## 太字

文字を`**`で囲みます。

```markdown
これは**重要な文字**です。
```

## 斜体

文字を`*`で囲みます。

```markdown
これは*斜体の文字*です。
```

## 強調色

文字を`==`で囲むと、アクセントカラーで表示されます。

```markdown
これは==特に伝えたい部分==です。
```

太字と組み合わせることもできます。

```markdown
**==最も重要な部分==**
```

`==文字==`は「ポンっ！」独自の記法です。

## リンク

```markdown
[表示する文字](https://example.com)
```

例：

```markdown
[GitHubを開く](https://github.com/wvyrbnyq3t/markdown-to-pptx)
```

# リスト

## 箇条書き

```markdown
- 項目1
- 項目2
- 項目3
```

## 番号付きリスト

```markdown
1. 手順1
2. 手順2
3. 手順3
```

## ネスト付きリスト

行の先頭へ空白を追加すると、リストを入れ子にできます。

```markdown
- 親項目
  - 子項目
  - 子項目
- 次の親項目
```

箇条書きの中へ番号付きリストを入れることもできます。

```markdown
- 発表の準備
  1. 内容を考える
  2. スライドを作る
  3. 発表を練習する
```

# 引用

行の先頭へ`>`を付けます。

```markdown
> これは引用文です。
```

複数行の引用も作成できます。

```markdown
> これは引用文の1行目です。
> これは引用文の2行目です。
```

引用を入れ子にする場合は、`>>`を使用します。

```markdown
> 外側の引用
>
>> 内側の引用
```

# 表

GFM形式のMarkdown表を使用できます。

```markdown
| 項目 | 内容             | 状態   |
| ---- | ---------------- | ------ |
| 入力 | Markdownを入力   | 完了   |
| 確認 | プレビューを確認 | 作業中 |
| 出力 | PPTXとして保存   | 未実施 |
```

先頭行は表のヘッダーとして扱われます。

## 表の文字位置

区切り行のコロンで、列ごとの文字位置を指定できます。

```markdown
| 左揃え   | 中央揃え | 右揃え |
| :------- | :------: | -----: |
| テキスト |   中央   |    100 |
| テキスト |   中央   |    200 |
```

| 記述    | 配置     |
| ------- | -------- |
| `:---`  | 左揃え   |
| `:---:` | 中央揃え |
| `---:`  | 右揃え   |

## 表のデザイン

- ヘッダー行だけ背景色が設定されます。
- ヘッダー以外のセルは塗りつぶされません。
- ヘッダー文字色は背景色から自動的に白または黒が選ばれます。
- セルの上下余白は16pxです。
- セルの左右余白は20pxです。
- 表の角丸はありません。

表は横幅を多く使用するため、基本的には1列または2列レイアウトでの使用がおすすめです。

# コードブロック

コードを3つのバッククォートで囲みます。

````markdown
```ts
const message = "Hello";
console.log(message);
```
`````

最初のバッククォートの後ろへ言語名を書くと、コードブロックの上部へ表示されます。

````markdown
```python
def greet(name):
    return f"Hello, {name}"
```
````

コードブロックの文字サイズと背景色は、スライド設定から変更できます。

# 数式

## 文章内の数式

数式を`$`で囲みます。

```markdown
質量とエネルギーの関係は $E = mc^2$ です。
```

## 独立した数式

数式を`$$`で囲みます。

```markdown
$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

プレビューではKaTeX、PPTX出力ではMathJaxから生成したSVGが使用されます。

# グリッドレイアウト

スライドのコンテンツを横方向に分割できます。

スライドタイトルとページ番号は分割されず、タイトルより下のコンテンツ領域だけがグリッドになります。

## 2列レイアウト

```markdown
# 2列のスライド

<!-- grid: 2 -->

## 左側

左側の内容です。

<!-- column -->

## 右側

右側の内容です。
```

## 3列レイアウト

```markdown
# 3列のスライド

<!-- grid: 3 -->

## 1列目

1列目の内容です。

<!-- column -->

## 2列目

2列目の内容です。

<!-- column -->

## 3列目

3列目の内容です。
```

## 4列レイアウト

```markdown
# 4列のスライド

<!-- grid: 4 -->

## 1列目

内容

<!-- column -->

## 2列目

内容

<!-- column -->

## 3列目

内容

<!-- column -->

## 4列目

内容
```

## グリッド記法

| 記述               | 動作                  |
| ------------------ | --------------------- |
| `<!-- grid: 2 -->` | コンテンツを2列に分割 |
| `<!-- grid: 3 -->` | コンテンツを3列に分割 |
| `<!-- grid: 4 -->` | コンテンツを4列に分割 |
| `<!-- column -->`  | 次の列へ移動          |

グリッド指定がない場合は、通常の1列レイアウトになります。

## グリッドを使うときの注意

* 列数が増えるほど、1列あたりの横幅は狭くなります。
* 4列以上では、短い見出しや短い説明が適しています。
* 長文、コード、表、長い数式は1列または2列がおすすめです。
* 列ごとのコンテンツ量をそろえると、見やすくなります。
* 次の列へ移動するときは`<!-- column -->`を記述します。

# スライド作成のコツ

## 1枚に情報を入れすぎない

1枚のスライドへ文章を詰め込みすぎると、文字が小さくなったり、スライド領域を超えたりする場合があります。

内容が多い場合は、複数のスライドへ分けてください。

## 1枚につき1つのメッセージにする

```markdown
# このスライドで伝えたいこと

- 根拠1
- 根拠2
- 根拠3
```

スライドごとに伝えたい内容を1つへ絞ると、読みやすくなります。

## 見出しとリストを組み合わせる

```markdown
# アプリの特徴

## 簡単

- テキストを入力するだけ
- 難しい操作が不要

## 便利

- プレビューをすぐ確認
- PPTXとして保存
```

長い文章をそのまま書くよりも、見出しと箇条書きを組み合わせると整理しやすくなります。

## 強調色を使いすぎない

```markdown
このアプリの特徴は、==テキストを入力するだけ==でスライドを作成できることです。
```

本当に重要な部分だけを強調すると、伝えたい箇所が分かりやすくなります。

# 開発環境で使用する

## リポジトリを取得する

```bash
git clone https://github.com/wvyrbnyq3t/markdown-to-pptx.git
cd markdown-to-pptx
```

## 依存パッケージをインストールする

```bash
npm install
```

`package.json`と`package-lock.json`が同期している場合は、次のコマンドも使用できます。

```bash
npm ci
```

## 開発サーバーを起動する

```bash
npm run dev
```

表示されたURLをブラウザで開いてください。

## 本番用にビルドする

```bash
npm run build
```

## ビルド結果を確認する

```bash
npm run preview
```

# 注意事項

* 見出し1は、スライドタイトルとスライド区切りとして扱われます。
* 見出し1より前の内容は、タイトルのないスライドになる場合があります。
* `==文字==`は「ポンっ！」独自の記法です。
* `<!-- grid: 数値 -->`と`<!-- column -->`も独自の記法です。
* プレビューとPowerPointでは、文字の折り返し位置が異なる場合があります。
* 使用するフォントやPowerPointの環境によって見え方が変わる場合があります。
* 長い文章や大量の要素を1枚へ配置すると、文字が縮小される場合があります。
* 列数の多いグリッドへ表や長文を配置すると、内容が読みづらくなる場合があります。
* PPTX出力後は、PowerPoint上でも最終的なレイアウトを確認してください。
