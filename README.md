# 『ポンっ！』

**テキストを入力するだけで、スライドがポンっと完成。**

「ポンっ！」は、入力したMarkdownテキストからスライドを自動作成し、PowerPoint形式（`.pptx`）で保存できるWebアプリです。

難しいレイアウト操作をしなくても、文章・見出し・リストなどを入力するだけで、スライドの形へ自動的に変換されます。

## できること

- 入力したテキストをリアルタイムでスライド化
- Markdownを知らなくても「要素を追加」から入力可能
- スライドをブラウザ上でプレビュー
- 文字サイズ・色・余白などを変更
- 2列以上のグリッドレイアウトを作成
- 箇条書き・番号付きリストを作成
- 太字・斜体・強調色を使用
- 引用・コード・数式を表示
- 全画面でプレゼンテーションを確認
- PowerPoint形式（`.pptx`）で出力
- Markdownファイルを読み込み・保存

## 基本的な使い方

### 1. スライドの内容を入力する

画面のMarkdown入力欄へ、スライドにしたい内容を入力します。

```markdown
# はじめに

ポンっ！は、テキストからスライドを作成できるアプリです。

## 特徴

- テキストを入力するだけ
- スライドを自動作成
- PPTX形式で保存可能
```

入力した内容は、自動的にスライドプレビューへ反映されます。

### 2. プレビューを確認する

画面のプレビュー領域で、作成されたスライドを確認します。

Markdownを変更すると、プレビューもリアルタイムで更新されます。

### 3. スライドのデザインを変更する

ヘッダーの「スライド設定」から、次の項目を変更できます。

- スライドの背景色
- メインカラー
- アクセントカラー
- 本文の文字色
- スライドタイトルの文字サイズ
- 小見出しの文字サイズ
- 本文の文字サイズ
- コードの文字サイズ
- コードブロックの背景色
- 数式の文字サイズ
- スライド内の余白
- コンテンツ間の余白
- ページ番号の表示
- タイトルスライドの表示

変更した設定はブラウザへ保存され、次回アプリを開いたときにも引き継がれます。

### 4. 全画面表示で確認する

プレゼンテーションボタンを押すと、スライドを全画面で確認できます。

主な操作は次のとおりです。

| 操作               | 動作             |
| ------------------ | ---------------- |
| `←`                | 前のスライド     |
| `→`                | 次のスライド     |
| `Space`            | 次のスライド     |
| `Escape`           | 全画面表示を終了 |
| 画面左側をクリック | 前のスライド     |
| 画面右側をクリック | 次のスライド     |

### 5. PowerPointとして保存する

ヘッダーの「PPTXを出力」を押すと、作成したスライドをPowerPoint形式で保存できます。

出力するファイル名は、Markdown入力欄の上部から変更できます。

# Markdownを知らない場合

Markdownの記述方法を覚えていなくても、画面の「＋」ボタンから要素を追加できます。

## 要素を追加する

1. Markdown入力欄で、要素を追加したい位置をクリックします。
2. 画面右下の「＋」ボタンを押します。
3. 下から表示される要素一覧から、追加したい要素を選びます。
4. 選んだ要素に対応するMarkdownが、カーソル位置へ挿入されます。
5. 選択状態になっている仮の文字を、そのまま書き換えます。

## 選べるカテゴリー

要素一覧の上部には、カテゴリーを切り替えるボタンがあります。

カテゴリー部分は横方向へスクロールできます。

### スライド

- 新しいスライド
- 2列レイアウト
- 3列レイアウト
- その他のグリッドレイアウト
- 次の列

### 文章

- 小見出し
- コンテンツ見出し
- 本文
- 引用

### リスト

- 箇条書き
- 番号付きリスト

### 文字装飾

- 太字
- 斜体
- 強調色
- リンク

### その他

- コードブロック
- インライン数式
- ブロック数式

## 選択した文字を装飾する

Markdown入力欄で文字を選択してから「要素を追加」を押すと、選択した文字へ装飾を適用できます。

例えば、次の文字を選択します。

```text
重要な部分
```

「太字」を選ぶと、次のように変換されます。

```markdown
**重要な部分**
```

「強調色」を選ぶと、次のように変換されます。

```markdown
==重要な部分==
```

# スライドの作り方

## 新しいスライドを追加する

見出し1を記述すると、新しいスライドが作成されます。

```markdown
# スライドタイトル
```

複数のスライドを作る場合は、スライドごとに見出し1を記述します。

```markdown
# 1枚目のスライド

1枚目の内容です。

# 2枚目のスライド

2枚目の内容です。

# 3枚目のスライド

3枚目の内容です。
```

見出し1は、スライドタイトルとページの区切りを兼ねています。

Markdownの記述に慣れていない場合は、「要素を追加」から「新しいスライド」を選択してください。

## 小見出しを追加する

見出し2は、スライド内の小見出しとして表示されます。

```markdown
## 小見出し
```

小見出しの文字色には、スライド設定のアクセントカラーが使用されます。

## コンテンツ見出しを追加する

見出し3以降は、本文中の見出しとして表示されます。

```markdown
### コンテンツ見出し
```

```markdown
#### より小さな見出し
```

```markdown
##### 見出し5
```

```markdown
###### 見出し6
```

# 文章の書き方

## 本文

通常の文章は、そのまま入力します。

```markdown
これはスライドの本文です。
```

文章の途中で改行しても、同じ段落として扱われる場合があります。

別の段落にしたい場合は、文章の間に空行を入れます。

```markdown
これは1つ目の段落です。

これは2つ目の段落です。
```

## 太字

文字を`**`で囲みます。

```markdown
これは**重要な文字**です。
```

## 斜体

文字を`*`で囲みます。

```markdown
これは*斜体の文字*です。
```

## 強調色

文字を`==`で囲むと、アクセントカラーで表示されます。

```markdown
これは==特に伝えたい部分==です。
```

太字と組み合わせる場合は、次のように記述します。

```markdown
**==最も重要な部分==**
```

`==文字==`は「ポンっ！」独自の記法です。

## リンク

```markdown
[表示する文字](https://example.com)
```

例：

```markdown
[GitHubを開く](https://github.com/wvyrbnyq3t/markdown-to-pptx)
```

# リストの書き方

## 箇条書き

各項目の先頭へ`-`を付けます。

```markdown
- 項目1
- 項目2
- 項目3
```

## 番号付きリスト

各項目の先頭へ番号を付けます。

```markdown
1. 手順1
2. 手順2
3. 手順3
```

## ネストしたリスト

行の先頭へ空白を追加すると、リストを入れ子にできます。

```markdown
- 親項目
  - 子項目
  - 子項目
- 次の親項目
```

箇条書きの中へ、番号付きリストを入れることもできます。

```markdown
- 発表の準備
  1. 内容を考える
  2. スライドを作る
  3. 発表を練習する
```

# 引用

行の先頭へ`>`を付けます。

```markdown
> これは引用文です。
```

複数行の引用も作成できます。

```markdown
> これは引用文の1行目です。
> これは引用文の2行目です。
```

引用を入れ子にする場合は、`>>`を使用します。

```markdown
> 外側の引用
>
>> 内側の引用
```

# コードブロック

コードを3つのバッククォートで囲みます。

````markdown
```ts
const message = "Hello";
console.log(message);
```
`````

最初のバッククォートの後ろへ言語名を書くと、コードブロックの上部へ表示されます。

使用例：

````markdown
```python
def greet(name):
    return f"Hello, {name}"
```
````

コードブロックの文字サイズと背景色は、スライド設定から変更できます。

# 数式

## 文章内の数式

数式を`$`で囲みます。

```markdown
質量とエネルギーの関係は $E = mc^2$ です。
```

## 独立した数式

数式を`$$`で囲みます。

```markdown
$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

# グリッドレイアウト

スライドのコンテンツを横方向に分割できます。

スライドタイトルとページ番号は分割されず、タイトルより下のコンテンツ領域だけがグリッドになります。

## 2列レイアウト

```markdown
# 2列のスライド

<!-- grid: 2 -->

## 左側

左側の内容です。

<!-- column -->

## 右側

右側の内容です。
```

## 3列レイアウト

```markdown
# 3列のスライド

<!-- grid: 3 -->

## 1列目

1列目の内容です。

<!-- column -->

## 2列目

2列目の内容です。

<!-- column -->

## 3列目

3列目の内容です。
```

## 4列以上のレイアウト

対応している範囲内で、列数を数値で指定できます。

```markdown
# 4列のスライド

<!-- grid: 4 -->

## 1列目

内容

<!-- column -->

## 2列目

内容

<!-- column -->

## 3列目

内容

<!-- column -->

## 4列目

内容
```

## グリッド記法

| 記述               | 動作                  |
| ------------------ | --------------------- |
| `<!-- grid: 2 -->` | コンテンツを2列に分割 |
| `<!-- grid: 3 -->` | コンテンツを3列に分割 |
| `<!-- grid: 4 -->` | コンテンツを4列に分割 |
| `<!-- column -->`  | 次の列へ移動          |

グリッド指定がない場合は、通常の1列レイアウトになります。

## グリッドを使うときの注意

* 列数が増えるほど、1列あたりの横幅は狭くなります。
* 4列以上では、短い見出しや短い説明が適しています。
* 長文・コード・長い数式は、1列または2列がおすすめです。
* 列ごとのコンテンツ量をそろえると、見やすいスライドになります。
* 列を移動するときは、`<!-- column -->`を記述します。

# Markdownファイルを使う

## Markdownファイルを開く

「Markdownを開く」から、端末内のMarkdownファイルを読み込めます。

読み込んだMarkdownは、エディター上でそのまま編集できます。

## Markdownファイルを保存する

「Markdownを保存」から、編集中の内容をMarkdownファイルとして保存できます。

PPTXを出力する前にMarkdownも保存しておくと、後から内容を修正できます。

# メニュー

ヘッダー左側のハンバーガーメニューから、使い方や関連ページを開けます。

メニュー外の背景、閉じるボタン、または`Escape`キーでメニューを閉じられます。

# スライド作成のコツ

## 1枚に情報を入れすぎない

1枚のスライドへ文章を詰め込みすぎると、文字が小さくなったり、スライド領域を超えたりすることがあります。

内容が多い場合は、複数のスライドへ分けてください。

## 1枚につき1つのメッセージにする

スライドごとに伝えたい内容を1つへ絞ると、読みやすくなります。

```markdown
# このスライドで伝えたいこと

- 根拠1
- 根拠2
- 根拠3
```

## 見出しとリストを組み合わせる

長い文章をそのまま書くよりも、見出しと箇条書きを組み合わせると整理しやすくなります。

```markdown
# アプリの特徴

## 簡単

- テキストを入力するだけ
- 難しい操作が不要

## 便利

- プレビューをすぐ確認
- PPTXとして保存
```

## 強調色を使いすぎない

重要な部分だけを`==`で囲むと、伝えたい箇所が分かりやすくなります。

```markdown
このアプリの特徴は、==テキストを入力するだけ==でスライドを作成できることです。
```

# 注意事項

* 見出し1は、スライドタイトルとスライド区切りとして扱われます。
* 見出し1より前の内容は、タイトルのないスライドになる場合があります。
* `==文字==`、`<!-- grid: 数値 -->`、`<!-- column -->`は、このアプリ独自の記法です。
* ブラウザ上のプレビューとPowerPointでは、文字の折り返し位置が異なる場合があります。
* 使用するフォントやPowerPointの環境によって、見え方が変わる場合があります。
* 長い文章や大量の要素を1枚へ配置すると、文字が縮小される場合があります。
* PPTX出力後は、PowerPoint上でも最終的なレイアウトを確認してください。
